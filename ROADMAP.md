# Roadmap

Folio stays small. Prefer one sharp improvement over a platform.

## Next

- [ ] Tag `v0.2.0` and flip the repo public
- [ ] Message-level chat index (better snippets for long exports)
- [ ] Optional HEIC decode without relying on OS converters
- [ ] `folio ingest letter` IMAP fetch behind an explicit opt-in flag
- [ ] Signed release binaries (goreleaser)

## Non-goals

- Cloud sync accounts
- Always-on screen recording / Rewind-style capture
- Docker-required installs
- Reading encrypted messenger databases
